# Как выложить PeSafe бесплатно

Есть два способа. Оба бесплатные и дают HTTPS-ссылку: на телефоне работают микрофон, GPS и запись.

| | Способ 1: Netlify Drop | Способ 2: Render |
|---|---|---|
| Время | 1 минута | 10–15 минут |
| SOS, отсчёт, GPS, датчики, запись, SMS, звонки, 112 | ✅ | ✅ |
| Автоотправка близким в Telegram (текст + запись) | ❌ | ✅ |
| Нюанс | — | Бесплатный сервер «засыпает» через 15 мин без запросов (см. шаг 5) |

---

## Способ 1. Netlify Drop (быстро, без Telegram)

1. Откройте **https://app.netlify.com/drop** и войдите (можно через Google или GitHub).
2. Перетащите в окно папку **`C:\Users\sima\Desktop\sos\dist`**.
3. Скопируйте ссылку вида `https://имя.netlify.app` и откройте её на телефоне.
4. Установите как приложение: Android (Chrome) → ⋮ → «Установить приложение»; iPhone (Safari) → «Поделиться» → «На экран Домой».

После изменений в коде выполните `npm run build` и снова перетащите `dist` (Deploys → Drag and drop).

## Способ 2. Render (все функции, включая Telegram)

### Шаг 1. Загрузить код на GitHub
1. Зарегистрируйтесь на **https://github.com** (бесплатно).
2. Нажмите **New repository**, назовите репозиторий `pesafe`, выберите **Private** и **не** добавляйте README.
3. В PowerShell в папке проекта выполните:
   ```powershell
   cd C:\Users\sima\Desktop\sos
   git remote add origin https://github.com/ВАШ_ЛОГИН/pesafe.git
   git push -u origin main
   ```
   Откроется окно входа в GitHub, подтвердите вход.

### Шаг 2. Создать сервер на Render
1. Зарегистрируйтесь на **https://render.com** через GitHub. Банковская карта для бесплатного плана не нужна.
2. Выберите **New → Blueprint** и укажите репозиторий `pesafe`. Render найдёт файл `render.yaml`.
3. Поля `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_IDS` пока можно оставить пустыми. Нажмите **Apply**.
4. Через 3–5 минут появится ссылка `https://pesafe-xxxx.onrender.com`. Откройте её на телефоне.

### Шаг 3. Telegram-бот
1. В Telegram откройте **@BotFather**, отправьте `/newbot` и скопируйте **токен**.
2. Каждый близкий человек должен найти вашего бота и нажать **Start**.
3. В браузере откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Числа `"chat":{"id": ...}` — это **Chat ID**.
4. В Render откройте сервис **pesafe → Environment**:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_IDS` — Chat ID через запятую;
   - `DELIVERY_DRY_RUN` — `false`.
   Нажмите **Save Changes**, сервер перезапустится.

### Шаг 4. Подключить приложение
1. В Render, в разделе **Environment**, скопируйте значение `DELIVERY_ACCESS_KEY` (сгенерировано автоматически).
2. На телефоне откройте PeSafe → **Настройки → Подключение Telegram**, вставьте ключ и нажмите «Проверить подключение».
3. Включите **«Автоотправка близким»** и, если нужно, **«Голосовая запись при SOS»**.
4. Проверьте работу: нажмите SOS → «Нужна помощь сейчас». Близким должны прийти текст, геолокация и запись.

Ключ хранится только до закрытия вкладки. После перезапуска приложения его нужно ввести снова. Так задумано для безопасности.

### Шаг 5. Чтобы сервер не засыпал
Бесплатный Render засыпает через 15 минут без запросов, и первое обращение после этого занимает около минуты. Чтобы этого не было:
1. Зарегистрируйтесь на **https://cron-job.org** (бесплатно).
2. Создайте задание: URL `https://pesafe-xxxx.onrender.com/`, интервал **каждые 10 минут**.

Бесплатных 750 часов в месяц хватает, чтобы один сервис работал круглосуточно.

---

### Важно
- В учебном режиме (`DELIVERY_DRY_RUN=true`) никому ничего не отправляется.
- Автоматического вызова 112/МЧС нет: у службы нет публичного API. На экране SOS есть кнопка звонка 112 и готовый текст для диспетчера.
- На бесплатном Render журнал отправок (`.data`) очищается при перезапуске. На работу SOS это не влияет.
