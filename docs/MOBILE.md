# Android и iPhone

В репозитории созданы проекты `android/` и `ios/`. Это исходные оболочки Capacitor 8 с текущим foreground MVP. Фоновое прослушивание, детектор ДТП на ML, fullscreen поверх других приложений и автоматический звонок 112 в них не реализованы. Одной упаковки PWA для этих функций недостаточно.

## Android

Нужны Android Studio, подходящие JDK и Android SDK согласно [текущей документации Capacitor](https://capacitorjs.com/docs/getting-started/environment-setup). В исходном проекте min SDK 24, compile/target SDK 36; совместимость конкретного телефона и WebView требует проверки.

```powershell
npm install
npm run android
```

В Android Studio дождитесь Gradle Sync, выберите устройство и Run. Подписанный APK/AAB создаётся через стандартный процесс Build/Generate Signed Bundle с вашим keystore. Нельзя коммитить ключи подписи. В этой среде Android SDK/JDK отсутствуют, поэтому APK не создан и Gradle-сборка не проверена.

Manifest содержит foreground-разрешения микрофона и геолокации, вибрацию и интернет. Автобэкап отключён, чтобы не переносить медкарту незаметно. Не запрашиваются SMS send, overlay, background location, full-screen intent или microphone foreground service: этих функций пока нет.

## iPhone

Для сборки нужен Mac с Xcode и учётная запись разработчика Apple для соответствующего способа установки. Windows может подготовить web assets и исходники Xcode, но не собрать IPA.

```sh
npm install
npm run ios
```

Откроется Xcode-проект; задайте Team и signing, уникальный Bundle ID, подключите iPhone, выполните Run. Проект использует Swift Package Manager. В Info.plist добавлены описания microphone/location/motion; `UIBackgroundModes` намеренно не заявлены, поскольку фонового сервиса нет. Режим голосового Web Speech API может быть недоступен в WKWebView — ручной SOS и другие датчики не должны от этого зависеть.

## Серверный канал в установленном приложении

Bundled-приложение не содержит Node-сервер. Для Telegram требуется отдельно развёрнутый собственный HTTPS gateway с конфигурацией из `.env.example`.

На сервере:

```dotenv
NATIVE_ORIGINS=capacitor://localhost,https://localhost
```

Перед сборкой приложения в PowerShell:

```powershell
$env:PESAFE_API_URL='https://your-own-pesafe-domain.example'
npm run mobile:sync
```

Подставьте ваш настоящий HTTPS origin, без пути и секретов. `scripts/build.js` запишет его в `dist/runtime-config.js`; `cap sync` копирует assets в обе платформы. Без `PESAFE_API_URL` нативная сборка остаётся локальным MVP: ручной SOS/SMS работают в пределах возможностей ОС, серверный канал не подключится.

На Mac используйте `PESAFE_API_URL=https://... npm run mobile:sync`. Не коммитьте адрес приватного контура, если он чувствителен. Ключ подключения вводится пользователем в настройках и живёт только в памяти текущего запуска. Для production заменить это на привязку устройства и native secure storage.

## Матрица проверки на физических устройствах

| Сценарий | Android | iPhone |
|---|---|---|
| Первый запуск, профиль, закрытие клавиатуры, safe area | Обязательно | Обязательно |
| Разрешить/запретить микрофон, GPS, motion | Обязательно | Обязательно |
| Наушники, музыка, активный звонок | Обязательно | Обязательно |
| Тихая речь, шум, падение телефона, поездка | Обязательно | Обязательно |
| Сворачивание: индикатор паузы, остановка аудио | Обязательно | Обязательно |
| Перезагрузка во время countdown/active | Обязательно | Обязательно |
| Offline, плохой GPS, потеря Telegram, неизвестная квитанция | Обязательно | Обязательно |
| Системные SMS/tel/share с тестовыми контактами | Обязательно | Обязательно |
| VoiceOver/TalkBack, крупный шрифт, reduced motion | Обязательно | Обязательно |
| Фоновый режим/заблокированный экран | Не поддержан | Не поддержан |

Не тестируйте автоматическими или ложными обращениями на 112. Для полевых испытаний используйте учебный сценарий, свои согласованные тестовые контакты и отдельный gateway. Завершение всех строк на устройствах ещё предстоит.
